# v0.2.5 - Dynamic Module Loading Support

## Features

### Dynamic Module Loading with Search Params

Enhanced the virtual entrypoints resolver to support dynamic module loading with query parameters. The plugin now correctly handles module imports with search params, enabling dynamic module resolution patterns.

**Example:**

```typescript
// Now supported:
import Component from "some/path/_file_.tsx?dynamic=abc123";
```

This enables advanced use cases such as:

- Cache-busting strategies
- Dynamic module variants
- Parameter-based module resolution
- HMR with query-based invalidation

## Technical Details

Updated the regex filter in the `virtual-entrypoints-loader` plugin to match paths with optional query parameters: `(\\?.*)?$`

This allows the build system to properly resolve virtual entrypoints regardless of whether they include search params or not.
