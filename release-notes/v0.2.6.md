# v0.2.6 - Improved Hydration & Build Refresh

## Features

### Better Hydration Handling

Enhanced hydration logic to be fully compatible with streaming. This ensures proper client-side hydration when using React's streaming SSR capabilities.

### Build Trigger Client Refresh

The plugin now triggers a client refresh even when other plugins initiate a build. This ensures the client stays in sync with the latest changes regardless of which plugin triggered the rebuild.
